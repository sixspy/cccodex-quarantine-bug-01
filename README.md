## 入舱落点（甲边：切流账册）

- **形态**：入舱与落点行同一次事务写完；落点行锁「条目键 + 舱码」指纹，二次入舱即回刷，必拒。
- **现行读引用**：恒为 `cutover_book`，清洗编排只读账册；旧轨与双写两轨脚手架已拆除，防止两套同开。
- **清洗闸门**：任一「入舱」标记缺落点行、或落点指纹拧花，编排整批拒绝（409），不吞漂件。
- **三件套**：入舱标记 / 坏件余数 / 入舱落点，在舱卡片、抓取侧、复核、对账、台参数五处同屏可见。
- **半失败**：整次写入回滚，错误回中随即短句，坏件余数维持原样。
